# VR-тренажёр обслуживания оборудования

Небольшой сценарий на Unity 6 для ПК и VR. Нужно последовательно отключить питание рубильником, установить сменную деталь в подходящее крепление и удерживать инструмент в рабочей зоне две секунды. Действия в неверном порядке не продвигают сценарий: появляется подсказка. После завершения доступны перезапуск и возврат в меню.

## Запуск

- Версия Unity: **6000.5.9f1**.
- Откройте сцену `Assets/Scenes/MainMenu.unity` и запустите Play Mode.
- Для проверки в редакторе выберите **Use Asset Database (fastest)** в `Window > Asset Management > Addressables > Groups > Play Mode Script`. Сцена мастерской загружается через Addressables по адресу `Scenes/Workshop`.
- Для сборки под Windows используйте **Tools > Build Windows Trainer**. Команда сначала собирает Addressables, затем создаёт приложение в `Builds/Windows/`. При необходимости Addressables и Windows-сборку можно выполнить отдельно через соответствующие окна Unity.

## Управление на ПК

1. Нажмите левой кнопкой мыши на рубильник.
2. Возьмите зелёную сменную деталь и нажмите на зелёное крепление. Красное крепление не подходит.
3. Возьмите инструмент, наведите курсор на жёлтую рабочую зону и удерживайте левую кнопку мыши две секунды.

Правая кнопка мыши возвращает удерживаемую деталь или инструмент на место. `Esc` открывает главное меню. После выполнения задания доступны кнопки **Заново** и **В меню**.

## Структура проекта

- `Assets/Scenes` — главное меню и мастерская.
- `Assets/Scripts/Core` — порядок действий и правила сценария.
- `Assets/Scripts/Interactables` — логика рубильника, детали, креплений и инструмента.
- `Assets/Scripts/App` — управление мышью, режим запуска и загрузка сцен.
- `Assets/Scripts/UI` — подсказки, прогресс и экран результата.
- `Assets/Editor/BuildWindows.cs` — команда сборки приложения под Windows.

Проект использует OpenXR, Input System, XR Interaction Toolkit и Addressables. Проверены режим ПК и XR Interaction Simulator в редакторе. С физическим VR-шлемом сценарий пока не тестировался.
